# Into the Deep: Solo Run

A single-file browser game based on FIRST Tech Challenge's Into the Deep (2024-25). Solo score attack in an isometric view.

- 30 s auto, 8 s transition, 2:00 teleop, ascent in the last 30 s
- Vertical lift and horizontal slide with 18 in body, 42 in length and 42 in height limits
- Human player clips samples dropped in the observation zone
- Rebindable keys, adjustable drive/lift/extension speeds, live scoreboard

Open `index.html` in a browser, or deploy the folder as a static site.

Point values and field dimensions are approximations. Check them against the official Game Manual Part 2.
